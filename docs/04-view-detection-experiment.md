## 结论

1. 视角状态在 8111 里**不可观测**，`hud_type` 等"可疑字段"全部证伪。
2. 视角检测**只能**走「V 键循环计数 + 重同步 + 手动兜底」方案（用户提出的方案），这条路确定为主方案。
3. 附带确认：停放状态下 `/state` 的 `AoA, deg`、`AoS, deg` 为**无意义的静态值**（−28.9 / −36.4），HUD 必须以 `valid` + IAS>0 判断"是否在飞"，否则地面会画出乱飞的姿态。

## 对实施方案的影响

- 视角模块：被动键盘钩子计 V（3 态循环）+ 重同步（载具 `type` 变化 / mission 状态 / 进程重启 / 重生）+ F9 强制第三人称 + F10 开关
- 必须提供"改键采样"，因为本机无可读按键配置
- 数据层增加"地面/空中"状态判定，地面时 HUD 隐藏或只显示降级信息
